# NCloud Digital — High-Growth Agency & Web Systems

A premium, modern web experience engineered for **NCloud Digital** (Digital Growth Systems, Meta Ads scaling, and Web Development Studio based in Colombo, Sri Lanka).

Built with **React**, **TypeScript**, **Vite**, **Tailwind CSS**, **Three.js**, **Framer Motion**, and **Lucide React**.

---

## 🌟 Experiences Included

1. **Classic Agency (Elevated)**
   - Interactive 3D Growth Engine (`GrowthCore3D.tsx`) with dynamic camera frustum calibration and mouse/touch parallax.
   - Editorial interactive split showcase for Services, Advantage breakdown, and 5-stage pipeline.
   - Verified performance metrics, Founder executive profile (Nethum Vidyalankara), interactive proposal consultation form, and Client Hub portal.
   - Smooth `ScrollReveal` transitions and tactile spring physics on all CTAs.

2. **NCloud 3D Experience**
   - High-contrast, typography-driven 3D creator & agency portfolio aesthetic with fluid marquee and interactive project showcases.

3. **NCloud Fintech (Halo Style)**
   - Ultra-clean fintech aesthetic on `#F5F5F5` canvas with TT Norms Pro typography.
   - Full-bleed ambient video hero container, 22s & 30s seamless brand marquees, interactive video use cases showcase, and complete NCloud business services & proof.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm or pnpm

### Installation
```bash
# Clone the repository
git clone https://github.com/Dulanja-SaMaEl/ncloud-digital.git

# Navigate to project directory
cd ncloud-digital

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
